# 單變量與多變量 LSTM 之股票價格預測績效比較


> **文件定位：**研究計畫摘要｜歷史設計文件。此文件記錄原始研究／實作規劃，不代表現行操作說明。最新實驗結果見[LSTM 與 GRU 正式實驗結果](LSTM%20與%20GRU%20股價預測正式實驗結果.md)；現行環境與命令請依 [README 操作章節](../README.md#環境資料與執行)。

## 課程報告研究計畫摘要｜資料來源選擇、研究目標與實驗設計

# 一、研究背景與目的

長短期記憶網路（Long Short-Term Memory, LSTM）常用於處理時間序列資料。本研究以股票歷史行情為例，探討輸入特徵的數量與類型是否影響 LSTM 對「下一交易日收盤價」的預測表現。研究重點不是證明 LSTM 一定能獲利，而是以公平的實驗比較，檢驗單變量、多變量與加入技術指標三種設定的預測差異。

# 二、資料來源與價格口徑

本研究使用臺灣證券交易所（TWSE）2330 個股日成交資訊，取得 2015 年 1 月至 2025 年 12 月的官方日線 OHLCV。專案保留每月查詢來源、原始回應 SHA256、交易日清單及行情快照 SHA256，供離線重現與核對。

本研究使用官方資料的原始未還原價格，不套用 Yahoo auto_adjust 或自行估計公司行動調整係數。成交量以股計。除權息等事件造成的價格跳空會保留，Close 與由 Close 計算的技術指標也維持未還原口徑。

因此預測目標是未還原的下一交易日 Close，MAE/RMSE 衡量名目價格誤差，不能解讀為含息總報酬或投資績效。這是本次研究採用的資料口徑與解釋限制；模型、資料切分及實驗設計仍沿用既定方案。
# 三、研究目標與研究問題

**研究目標：**控制 LSTM 架構、訓練流程與預測目標一致，觀察增加行情變數及技術指標後，是否能穩定降低預測誤差。

**RQ1：**僅使用歷史收盤價的單變量 LSTM，與使用 OHLCV 的多變量 LSTM，何者對下一交易日收盤價的預測誤差較低？

**RQ2：**在 OHLCV 基礎上加入 MA、RSI 與 MACD 等技術指標，是否能進一步改善模型表現？

**RQ3：**上述模型是否優於「以今日收盤價當作明日預測值」的簡單基準（Naive Baseline）？

# 四、資料處理與實驗設計

**研究對象：**台積電 2330.TW（可在課堂需求下替換）。資料期間：2015/01/01–2025/12/31。資料頻率：日線（交易日）。任務：使用截至第 t 日的過去 60 個交易日特徵，預測第 t+1 日收盤價。每一模型的預測日與評估樣本必須一致。

**時間切分：**訓練集 2015–2022 年、驗證集 2023 年、測試集 2024–2025 年。依日期順序切分，不隨機打亂；使用驗證集調整超參數，測試集只用於最終評估。

**模型 A｜**單變量 LSTM：輸入過去 60 日 Close，預測下一日 Close。

**模型 B｜**多變量 LSTM：輸入過去 60 日 Open、High、Low、Close、Volume，預測下一日 Close。

**模型 C｜**技術指標多變量 LSTM：在 OHLCV 之外加入 MA5、MA20、RSI(14)、MACD 線與訊號線，預測下一日 Close。

**基準模型｜**Naive Baseline：直接以第 t 日 Close 作為第 t+1 日 Close 的預測，用來判斷 LSTM 是否真正優於簡單方法。

**公平比較原則：**三組 LSTM 使用相同的時間窗、目標、主要網路架構、訓練策略與評估期間；只有輸入特徵不同。特徵縮放器僅用訓練集資料擬合，並套用到驗證及測試集；技術指標只使用預測當下已知的資料，避免未來資訊洩漏。必要時以多個隨機種子重複實驗，報告平均值及變異。

# 五、評估指標與結果呈現

MAE（平均絕對誤差）：衡量預測價格與實際價格的平均絕對差距；RMSE（均方根誤差）：對較大的預測誤差給予更高權重；方向正確率（Directional Accuracy）：判斷模型預測的次日漲跌方向是否與實際一致。Naive Baseline 的預測變動為 0，主要以 MAE 與 RMSE 進行比較。

**預計呈現：**① 三組 LSTM 與 Naive Baseline 的 MAE／RMSE 比較表；② 測試期間的真實價格與預測價格折線圖；③ 不同特徵組合的誤差及方向正確率比較；④ 對結果的解釋，例如更多變數是否帶來改善、噪音或過度擬合。

# 六、預期成果與研究限制

預期成果不是預設多變量一定勝出，而是建立可重現的比較流程，回答加入 OHLCV 與技術指標是否有實質幫助。如果改進幅度很小、無法超越簡單基準，或不同次訓練結果不一致，也屬於具有討論價值的研究發現。

**限制：**以單一股票與固定期間進行分析，結論未必能推廣到其他產業或市場；股價受突發事件影響，僅憑歷史技術特徵無法保證預測能力；本研究衡量的是預測誤差，不等同於投資報酬或交易策略績效。資料應遵守來源的使用條款。
