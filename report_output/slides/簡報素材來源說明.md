# 簡報素材來源說明

## 資料與結果

- 原始市場來源：TWSE STOCK_DAY，2330，非還原 OHLCV。課堂資料表取自 `res/research/2330.TW_2015-2025_twse.csv`；快照來源參數、月快取 SHA-256、資料與交易日曆摘要見兩個正式 run 的 `snapshot.metadata.json` 與 `evaluation/evaluation.json`。
- 正式結果：LSTM `results/20261120T134010119780Z_82eaad21/evaluation/metrics_summary.csv`；GRU `results/gru_20261120T143901617329Z_1fa00b5e/evaluation/comparison_summary.csv`。表格由上述 CSV 的完整精度均值、樣本 SD 四捨五入至小數 2 位。Naive MAE/RMSE 由 LSTM run 的 `evaluation/predictions_naive.csv` 之 `absolute_error`、`squared_error` 彙整（平均絕對誤差與平方誤差平均後開根號）。
- 特徵與設定：兩個 run 的 `config.json`；測試集樣本、日期範圍與資料/日曆雜湊見各 run 的 `evaluation/evaluation.json`。DA 為正式 summary CSV 的 directional_accuracy 欄，逐頁講稿中列出均值。± 為三個種子的樣本標準差（ddof=1），非信賴區間。
- 分布統計：slide evidence 的描述性統計：train raw Close 115–683 元；test 576–1,550 元；457/485（94.2268%）test Close 高於 train raw Close 上界。此結果僅描述分布，不是因果證明。

- 第 7 頁 MAE 圖以原生 PowerPoint 矩形、線段、文字刻度與誤差棒建構，所有元素可編輯；均值及樣本 SD 取自正式 summary CSV。

## 生成與重建

- `build_spec.py` 從正式資料/結果 CSV 產生 `slides_spec.json`、`content_manifest.json`、`逐頁講稿.md`、來源說明與曲線圖副本。
- `render_native.ps1` 以 PowerPoint COM 建立可編輯簡報、內嵌講者備註並匯出 PDF。
- 執行：`.venv\Scripts\python.exe -B report_output/slides/build_spec.py`，再執行 `powershell -NoProfile -File report_output/slides/render_native.ps1`。
