# 單變量與多變量 LSTM 股票價格預測比較：8 個 Commit 實作計畫

## 一、目標與交付成果

依據[研究計畫摘要](./單變量與多變量%20LSTM%20股票價格預測績效比較｜研究計畫摘要.md)，建立可重現的台積電股價預測實驗，比較輸入特徵是否改善下一交易日的預測績效。

採用已確認的交付方式：**可重現 Python 程式＋中文研究報告，實際跑完正式比較，固定參數、不做調參搜尋。**

最終交付包含：

- 行情資料快照，以及資料來源、下載參數與下載時間紀錄。
- 可重跑的資料處理、模型訓練、評估與報告產生指令。
- 三組 LSTM 各使用 3 個固定隨機種子，共 **9 次正式訓練**。
- Naive 基準、逐日預測結果、績效比較表與圖表。
- 中文 Markdown 研究報告，說明方法、實驗結果、限制與重現步驟。

專案採用 src/、res/、docs/ 結構；已取得 TWSE 官方個股日行情並建立含來源稽核與交易日清單的凍結快照。

## 二、研究設計與固定設定

### 資料、預測任務與比較組別

| 項目 | 固定設定 |
| --- | --- |
| 研究股票 | 台積電 `2330.TW` |
| 資料期間 | 2015/01/01–2025/12/31，日線、交易日資料 |
| 輸入與目標 | 使用過去 60 個交易日特徵，預測下一交易日的未還原 Close |
| 訓練集 | 2015–2022 年 |
| 驗證集 | 2023 年 |
| 測試集 | 2024–2025 年 |
| 模型 A | 單變量：Close，共 1 欄 |
| 模型 B | 多變量：Open、High、Low、Close、Volume，共 5 欄 |
| 模型 C | OHLCV 加上 MA5、MA20、RSI14、MACD 線與訊號線，共 10 欄 |
| Naive 基準 | 使用今日 Close 作為下一交易日 Close 的預測值 |

使用 TWSE 官方 STOCK_DAY 個股日成交資訊下載 2330 的 OHLCV，設定期間為 2015-01-01 至 2025-12-31，成交量保留官方股數。快照記錄來源參數、每月原始回應 SHA256、交易日清單與資料 hash。資料價格為未還原口徑，不套用自動還原或自行估計公司行動調整係數。

保存下載參數、下載時間、套件版本與資料 SHA256，後續實驗使用同一份行情快照重跑。既有快照不自動覆寫，避免不同模型使用到不同版本的資料。

### 公平比較與避免資料洩漏

1. 依日期排序，確認日期唯一，檢核必要欄位、缺值與價格資料。不額外補出週末或休市日。
2. MA 採用向後回看的移動平均；RSI14 使用 Wilder 平滑；MACD 固定為 12/26/9。技術指標固定實作與版本，只使用當下及過去資料，不以未來資料回填。
3. 以模型 C 的技術指標暖機期及完整 60 日視窗建立共同有效樣本，讓 A、B、C 與 Naive 的預測目標日期完全相同。
4. 依**預測目標日期**切分訓練、驗證與測試集。驗證及測試集的輸入視窗可以包含前一年度已知的歷史資料，避免在年度邊界丟失可用資訊。
5. X 與 y 分別使用 MinMaxScaler，僅以訓練集資料擬合，再套用至驗證與測試集。超出訓練範圍的值不裁切。
6. 採每日一步預測，使用預測當時已知的真實歷史資料，不將整段測試期間改成遞迴預測。
7. 使用驗證集的 loss 進行早停與權重選擇，凍結研究設定後才評估測試集。不依測試集結果挑選隨機種子、改模型或搜尋參數。

### 模型與訓練設定

| 項目 | 固定設定 |
| --- | --- |
| 網路架構 | 單向 `LSTM(64) → Dense(1)` |
| 最佳化器 | Adam，learning rate `0.001` |
| 損失函數 | MSE |
| Batch size | 32 |
| 最大訓練回合 | 100 epochs |
| 早停 | 監看 `val_loss`，`patience=10`，`restore_best_weights=True` |
| 訓練樣本順序 | `shuffle=False` |
| 固定隨機種子 | **42、43、44** |
| 正式訓練次數 | 三組模型各 3 次，共 **9 次** |

三組模型使用同一個模型建立函式及訓練流程，只有輸入特徵不同。輸入維度仍會造成參數量差異，因此另行記錄各組模型參數量，不宣稱三組完全等參數。

### 評估與結果呈現

預測值反正規化後，以未還原價格計算 MAE 與 RMSE，並以 **MAE 作為主要比較指標**。

方向正確率以今日 Close 為比較基準，判斷預測的下一日價格與真實下一日價格是否同屬上漲、下跌或持平：

```text
sign(預測下一日 Close - 今日 Close)
    == sign(真實下一日 Close - 今日 Close)
```

Naive 的預測變動固定為零，其方向正確率標示為 `N/A`，主要透過 MAE 與 RMSE 比較。

結果表保留每個種子的績效，再彙整平均值、樣本標準差，以及相對 Naive 的誤差改善率。價格折線圖固定展示 seed 42，不挑選測試表現最佳的種子，也不將多種子結果默認合併為 ensemble 預測。

研究不預設多變量一定勝出，也不將有限次重複訓練的差異宣稱為統計顯著。未超越 Naive、增加特徵未改善或不同種子結果不一致，都應如實呈現。

## 三、實作架構與 8 個 Commit

### 模組、設定與執行介面

在 `src/lstm_comparison/` 建立獨立研究套件，沿用專案的 `src/` 路徑慣例，保留既有 Notebook 與交易功能。以 Python 3.11、CPU 可執行為基線，建立可安裝的模組、環境設定與經驗證的鎖版相依套件。

JSON 設定檔包含資料路徑、研究期間、特徵組別、隨機種子與固定訓練參數。安裝套件後，提供以下三個指令；角括號部分為使用時需替換的路徑：

```text
python -m lstm_comparison download --config <設定檔>
python -m lstm_comparison run --config <設定檔>
python -m lstm_comparison report --run-dir <實驗目錄>
```

資料下載、正式實驗與報告產生分開執行。每個實驗目錄保存設定、資料 hash、環境資訊、縮放器、模型權重、訓練歷程及逐日預測，讓結果可以回溯至同一份資料與設定。

### 工作切分與驗收

| # | 建議 Commit Message | 內容與驗收 |
| --- | --- | --- |
| 1 | `chore(research): 建立研究環境與實驗設定` | 建立可安裝的研究模組、鎖版相依套件、JSON 設定與 CLI。驗收：乾淨環境可安裝套件，CLI help 正常，合法與不合法設定均有明確驗證結果。 |
| 2 | `feat(data): 新增 TWSE 官方未還原行情快照與資料檢核` | 使用既有 TWSE 快照並驗證來源、交易日與 hash，保存 CSV、metadata 與 hash，支援離線重讀同一快照。驗收：錯誤欄位、重複日期與缺值明確失敗，確認下載資料涵蓋研究期間且快照可重讀。 |
| 3 | `feat(features): 建立三組研究特徵與技術指標` | 建立 A、B、C 特徵，明確實作指標公式與暖機期。驗收：欄位數為 1、5、10，指標數值符合測試案例，修改未來資料不影響歷史特徵。 |
| 4 | `feat(dataset): 建立無資料洩漏的時序資料集` | 建立 60 日輸入與次日標籤、年度切分、訓練集專用縮放器及共同預測日期。驗收：年度邊界、標籤索引與 off-by-one 測試通過，訓練集外極值不改變縮放器，三組評估日期一致。 |
| 5 | `feat(model): 新增共用 LSTM 與重複訓練流程` | 共用模型建立與訓練流程，支援種子 42、43、44、早停、最佳權重及歷程保存。驗收：1、5、10 維輸入皆可短訓練，loss 與預測值為有限數值，早停與權重保存可正常使用。 |
| 6 | `feat(evaluation): 加入基準模型與績效比較` | 產生逐日預測、Naive 基準、價格誤差、方向正確率與種子彙總。驗收：手算案例與程式輸出一致，持平情況處理正確，Naive 使用前一交易日 Close，所有結果日期對齊。 |
| 7 | `feat(report): 產生研究圖表與報告` | 自動產生比較表、價格圖、誤差圖、方向正確率圖、訓練 loss 圖及中文研究報告。驗收：日期、單位與種子標示清楚，Naive 方向正確率為 N/A，報告依實際結果呈現，不預填勝出結論。 |
| 8 | `docs(research): 完成正式實驗與研究結果報告` | 實際完成 9 次正式訓練及 Naive 評估，補齊中文分析、限制與重現步驟。驗收：必要測試通過，模型評估日期一致，績效可以由逐日預測 CSV 重新計算，正式結果可追溯至資料快照與設定。 |

資料快照、設定、精簡結果與圖表納入版本控制；虛擬環境、快取及模型權重加入忽略規則。模型權重仍保存在本地實驗目錄，供結果追溯與重現時使用。

中文研究報告應包含研究方法、三組模型與 Naive 的比較結果、不同特徵組合的影響，以及單一股票、固定期間、隨機訓練差異等限制。

## 四、測試與完成標準

優先驗證會影響研究結論的資料與評估邏輯：

- **資料與特徵：**schema、日期排序與重複、缺值、技術指標暖機期，以及未來資料變更不影響歷史特徵的因果性。
- **時序資料集：**60 日輸入對應下一交易日標籤、跨年度切分、共同預測日期、訓練集外極值不影響縮放器，以及反正規化正確性。
- **評估：**可手算的 MAE、RMSE 與方向正確率案例，包含持平；Naive 使用前一交易日 Close；各組日期完全對齊。
- **整合流程：**先使用離線測試資料完成短訓練、評估與報告產生，再使用凍結的行情快照執行正式比較。

任務完成需同時符合以下條件：

1. 必要測試及整合檢查全部通過。
2. A、B、C 各完成 seed 42、43、44 的正式訓練，共 9 次，並完成同期間 Naive 評估。
3. 所有正式結果可追溯至同一份行情快照、設定及環境紀錄。
4. 指標可由保存的逐日預測 CSV 重新計算。
5. 中文報告完整回答特徵增加是否改善表現、是否優於 Naive，以及種子間表現是否一致；未改善的結果同樣如實記錄。

## 五、範圍與執行限制

本次不新增 Notebook、Web UI、交易回測、實際下單、多股票比較、其他模型或調參搜尋，也不重構 `Trading` 模組。既有 Notebook 與交易程式保留原有用途。

本計畫以 8 個 Commit 完成工作切分，預期不超過 10 個。若後續需求增加，先說明新增範圍及額外切分的理由，再調整計畫。

執行時間需在環境建立後，先透過短訓練量測，再估算正式實驗成本，不預先保證完成時間。若環境安裝、行情來源或資料品質阻擋正式比較，應明確回報尚未完成的部分，不以短訓練或預期數值冒充正式結果。

本文件為實作計畫；計畫書建立時尚未執行正式訓練。上述 Commit Message 為工作切分建議，不代表已建立提交。
